# Yuchen Bie Academic Homepage

This is a static GitHub Pages version of Yuchen Bie's academic homepage.

## Files

- `index.html`: homepage content
- `styles.css`: visual styling
- `CNAME`: custom domain setting, currently `eugene.ycbie`
- `Yuchen_Bie_CV.pdf`: optional CV file to add later

## GitHub Pages Setup

1. Create a GitHub repository named `<your-github-username>.github.io`.
2. Upload `index.html`, `styles.css`, `CNAME`, and this `README.md` to the repository root.
3. Go to repository `Settings` -> `Pages`.
4. Set source to `Deploy from a branch`, choose `main`, and choose `/root`.
5. Wait a few minutes, then visit `https://<your-github-username>.github.io/`.

## Custom Domain

The `CNAME` file uses:

```text
eugene.ycbie
```

For this to work publicly, the domain must be registered and DNS must point to GitHub Pages. If you do not own a resolvable domain yet, remove the `CNAME` file and use the default GitHub Pages URL first.

## Content To Replace

- Replace `your_email@example.com` in `index.html`.
- Add `Yuchen_Bie_CV.pdf` to the repository root when your CV is ready.
- Update links to Google Scholar, GitHub, or LinkedIn when available.
