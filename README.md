# Yuchen Bie Academic Homepage

A lightweight static academic homepage hosted with GitHub Pages.

## Structure

- `index.html` — homepage
- `research.html` — working paper and research experience
- `cv.html` — web CV plus an embedded downloadable PDF copy
- `profile.svg` — profile image wrapper
- `styles.css` — shared minimal academic styling

The site intentionally uses plain HTML/CSS rather than a Jekyll theme so it remains easy to edit and maintain.

GitHub Pages URL: https://ycbie.github.io/
